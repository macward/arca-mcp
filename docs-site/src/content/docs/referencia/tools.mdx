## Convenciones

- Casi todas las tools de red aceptan overrides `cert_path`, `key_path` y
  `environment` por llamada; si no se pasan, se resuelven desde el entorno.
- Las tools retornan modelos estructurados o un `ArcaError` con `{ cause, message }`.
  Ver [Errores](/arca-mcp/referencia/errores/).
